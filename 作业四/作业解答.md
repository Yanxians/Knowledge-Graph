## 一、请选择你的数据集
原始数据来自Github：https://github.com/lemonhu/stock-knowledge-graph/tree/master 数据内容主要为：  
* 1. 公司高管数据 (Executive Data) 数据来源：该部分数据是通过爬虫从 同花顺 (https://www.google.com/search?q=10jqka.com.cn) 的个股详情页抓取的。 
内容细节： 原始格式：存放在 data/stockpage.zip 压缩包中，解压后是数千个以股票代码命名的 .html 网页文件。  
提取信息：包含高管姓名、性别、年龄、所属股票代码、担任职位等。  
用途：在图谱中构建“人”与“公司（股票）”之间的 employ_of（任职）关系。  
* 2. 股票行业与概念数据 (Stock Industry & Concept Data) 数据来源：通过 Tushare 工具获取。  
Tushare 是一个国内常用的、基于 Python 的金融数据接口包，提供股票、基金、期货等金融行情和基本面数据。  
内容细节： 行业信息：记录每只股票所属的申万或其他分类行业。  
概念信息：记录股票所属的热门概念（如“人工智能”、“特斯拉概念”、“华为产业链”等）。  
用途：在图谱中构建“股票”与“行业”之间的 industry_of 关系，以及“股票”与“概念”之间的 concept_of 关系。

## 二、基于neo4j平台实现完整的知识图谱对话系统
### 2.1 导入数据到neo4j中
* 数据格式如下，已经被原作者整理成可以直接在Neo4j导入的格式：
<img width="914" height="383" alt="image" src="https://github.com/user-attachments/assets/3d9d4145-8ccd-4c40-8ec0-9925d55f8a34" />  

* 将csv文件放到neo4j的import文件夹后，运行代码直接导入：
LOAD CSV WITH HEADERS FROM 'file:///executive.csv' AS row WITH row WHERE row.`person_id:ID(Executive)` IS NOT NULL MERGE (e:Executive {id: row.`person_id:ID(Executive)`}) SET e.name = row.name,     e.gender = row.gender,     e.age = toInteger(row.`age:int`);  
LOAD CSV WITH HEADERS FROM 'file:///industry.csv' AS row WITH row WHERE row.`industry_id:ID(Industry)` IS NOT NULL MERGE (i:Industry {id: row.`industry_id:ID(Industry)`}) SET i.name = row.name;  
LOAD CSV WITH HEADERS FROM 'file:///stock.csv' AS row WITH row WHERE row.`stock_id:ID(Stock)` IS NOT NULL MERGE (s:Stock {id: row.`stock_id:ID(Stock)`}) SET s.name = row.name,     s.code = row.code;  
LOAD CSV WITH HEADERS FROM 'file:///concept.csv' AS row WITH row WHERE row.`concept_id:ID(Concept)` IS NOT NULL MERGE (c:Concept {id: row.`concept_id:ID(Concept)`}) SET c.name = row.name;   

LOAD CSV WITH HEADERS FROM 'file:///executive_stock.csv' AS row // 1. 根据 CSV 里的起始 ID 匹配高管节点 MATCH (e:Executive {id: row.`:START_ID(Executive)`}) // 2. 根据 CSV 里的结束 ID 匹配股票节点 MATCH (s:Stock {id: row.`:END_ID(Stock)`}) // 3. 创建关系，并将 jobs 字段存入关系属性 MERGE (e)-[r:EMPLOY_OF]->(s) SET r.jobs = row.jobs;   
LOAD CSV WITH HEADERS FROM 'file:///stock_concept.csv' AS row // 1. 匹配股票节点 (注意：这里的 id 必须与之前导入 Stock 时的属性名一致) MATCH (s:Stock {id: row.`:START_ID(Stock)`}) // 2. 匹配概念节点 (注意：这里的 id 必须与之前导入 Concept 时的属性名一致) MATCH (c:Concept {id: row.`:END_ID(Concept)`}) // 3. 创建关系，类型使用 CSV 中的 :TYPE (即 concept_of) MERGE (s)-[:CONCEPT_OF]->(c);   
LOAD CSV WITH HEADERS FROM 'file:///stock_industry.csv' AS row // 1. 匹配股票节点 MATCH (s:Stock {id: row.`:START_ID(Stock)`}) // 2. 匹配行业节点 MATCH (i:Industry {id: row.`:END_ID(Industry)`}) // 3. 创建关系 MERGE (s)-[:INDUSTRY_OF]->(i);
